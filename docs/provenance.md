# Provenance

This standalone edition is maintained by Yousef Mousa (`Robertsvg`). It starts
from the final public DeepKnight group-project revision:

- Source: <https://github.com/BatuCani/deepknight>
- Revision: `b30e6b514459673c4b900ea3838fb02bfeb9f6ec` (31 July 2026)
- Original contributors: Yousef Mousa, Batuhan Caniberk, and
  Adham Ahmed Mostafa Mohamed Ibrahim.

The complete engine, tests, experiment scripts, and historical benchmark data
are retained. The final technical report source is adapted for this edition:
student identifiers, signatures, submission declarations, and task-allocation
tables are omitted. Course handouts, planning documents, slide-generation
prompts, and intermediate submission reports are not part of the distribution.
The upstream repository remains the reference for the original project history.

The portfolio edition adds installation metadata, continuous integration,
maintainer-oriented documentation, and regression fixes for desktop startup,
console input, MCTS timing and RAVE selection, and self-play adjudication.
